# 公共基础 02：方向和任务数据模型

```text
请为 ByteOJ 新生方向探索设计 TypeScript 数据模型，不要实现页面。

模型至少包含：
1. Direction：方向 id、显示名、一句话说明、难度、预计时间、状态；
2. ExperienceTask：任务 id、方向、标题、步骤、交互类型、完成规则、反馈、下一步；
3. ExperienceRecord：开始时间、完成时间、用时、重试次数、是否完成、自评结果；
4. TaskStep：步骤标题、内容、选项、正确条件、错误提示和完成反馈。

要求：
- 方向状态支持 available、planned、disabled；
- 交互类型只支持 choice、sort、parameter、code-gap、result-check、chart-choice；
- 不加入职业诊断字段；
- 所有类型要方便后续 localStorage 序列化；
- 只输出设计和文件建议，不修改代码。
```
