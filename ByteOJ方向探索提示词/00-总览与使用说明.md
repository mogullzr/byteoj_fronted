# ByteOJ 方向探索提示词库

这是一套给 AI 编程助手使用的分阶段提示词。目标是逐步开发“面向新生的计算机方向探索”功能，而不是一次生成一个包含所有专业方向的大型平台。

## 目录结构

- `00-总览与使用说明.md`：使用规则、范围和开发顺序
- `01-公共基础/`：通用容器、数据模型、状态保存、方向地图、结果页
- `02-前端开发/`：前端方向体验任务
- `03-算法编程/`：算法方向体验任务
- `04-数据分析/`：数据分析方向体验任务
- `05-软件测试/`：软件测试方向体验任务
- `06-后端开发/`：后端方向的轻量模拟体验
- `07-数据库/`：数据库方向的轻量模拟体验
- `08-网络安全/`：安全认知和静态案例体验
- `09-嵌入式开发/`：嵌入式方向规划和模拟边界
- `10-移动端开发/`：移动端方向规划
- `11-游戏开发/`：游戏方向规划
- `12-云计算与DevOps/`：云计算方向规划
- `13-方向测试与发布/`：试用、质量、发布和复盘

## 使用方式

1. 先阅读本文件和 `01-公共基础`。
2. 先只实现一个方向，不要同时实现全部目录。
3. 每个文档对应一个独立任务，完成后运行项目并人工验证。
4. 只有前一个任务稳定后，才把下一个文档交给 AI。
5. 如果提示词要求“先分析”，AI 不得直接修改代码。
6. 如果任务范围没有明确涉及某模块，AI 不得重构或修改无关代码。

## 第一阶段建议顺序

1. 公共基础：方向地图
2. 公共基础：通用任务数据模型
3. 公共基础：任务容器
4. 前端开发：第一个体验任务
5. 算法编程：第一个体验任务
6. 数据分析：第一个体验任务
7. 软件测试：第一个体验任务
8. 公共基础：探索结果页
9. `13-方向测试与发布`：找新生试用

如果四个低成本方向不能让用户完成并愿意继续，不要增加更多方向。

## 全局项目背景提示词

```text
你正在已有的 Vue 3 + TypeScript + Vue Router 项目 ByteOJ 中工作。请先阅读现有代码，再修改代码。项目已有算法题库、在线判题、考试、课程、社区和 AI 页面，不能破坏这些功能。

本次功能面向刚进入大学、还不知道该学习什么的计算机新生。目标不是做职业性格测试，不是替用户决定职业，也不是做 LeetCode 替代品，而是让用户用几分钟完成一个低门槛任务，再决定是否愿意继续了解某个方向。

除非任务明确要求，否则：
1. 不新增大型依赖；
2. 不要求用户安装软件或注册；
3. 不调用 AI；
4. 不接入真实硬件、真实攻击目标或生产服务器；
5. 不修改无关路由和业务；
6. 不把模拟体验描述成真实职业能力；
7. 必须考虑移动端；
8. 必须说明修改文件和验证方式。
```
